# MGC-012-P5-T013 — Pin the integrity components and the outbox cardinality guard

대상: round 11 `R-7`, `R-8` (Blocking-P2). mutation `M39`, `M40` 은 round 11 에서 **SURVIVED**
였다. 결정: `D-038`.

**실제 동작 결함이 아니다.** 세 guard 는 오늘 맞게 동작한다. 없는 것은 그 정확성을 붙잡는
test 다. `src/` 는 수정하지 않았다.

## What Was Unprotected

| 대상 | 성분 | 잃으면 |
|---|---|---|
| `review_cards.py` `_command_for_event` root 대조 | 저장된 canonical `payload_json` | 저장된 payload 가 밖에서 바뀌어도 Card 를 만든다 |
| `events.py` `reconcile_connection` 감사 대조 | `audit.actor_id` | 다른 reviewer 이름으로 기록된 요청이 정상 통과한다 |
| `review_cards.py` `request()` | `len(outbox) != 1` | 한 요청이 두 Card 를 배달할 수 있다 (FR-013, FR-015) |

## Isolating One Component At A Time (AC-05)

성분 여럿을 동시에 어긋나게 하면 다른 guard 가 먼저 걸려 무엇이 잡았는지 알 수 없다. 그러면
겨냥한 guard 를 고정한 것이 아니다. round 11 이 `T006` evidence 의 "무결성 대조는 전부 도달
불가" 를 부분 오류로 정정한 이유가 이것이다.

**root 대조**: 검사는 세 성분이다 — `row[1] != digest`, `row[2] != canonical`,
`event.payload_digest != digest`. `digest` 는 저장된 값이 아니라 payload 에서 **다시 계산한**
값이다. 그래서 저장된 `payload_json` 만 바꾸면 digest 두 성분은 여전히 맞고 겨냥한 성분 하나만
어긋난다. test 가 digest column 이 안 바뀐 것을 명시적으로 확인한다.

```python
assert after == (stored[0],), "digest 성분은 그대로 둔다. 어긋나는 것은 JSON 하나뿐이다"
```

**감사 대조**: audit row 의 `actor_id` 만 바꾼다. `review[9]` 쪽을 바꾸면 위의 `payload_root`
검사가 먼저 잡는다.

**UPDATE 트리거를 먼저 지운다.** 트리거는 정상 경로를 지키고, 무결성 대조는 **파일이 밖에서
바뀐 경우**를 지킨다. 후자를 재현하려면 전자를 치워야 한다. 이것이 두 방어선이 서로 대체하지
않는다는 근거다.

**개수 guard**: `_append_review_card_in_transaction` 이 event 를 둘 돌려주도록 monkeypatch 한다.
정상 경로로는 만들 수 없는 상태이므로 collaborator 를 바꾸는 것이 옳은 방법이다.
