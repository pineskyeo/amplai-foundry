# MGC-012-P5-T012 — Make the safe outcome set contract true

대상: round 11 `R-4`, `R-5` (Blocking-P2). 결정: `D-038`, `D-034`.

## The Two Defects

**`R-4` — 동어반복 test.** `test_every_safe_outcome_value_has_a_producer` 가 `produced` 를
enum 자신에서 hardcoded 문자열 집합으로 걸러 만들고 그것을 다시 enum 과 비교했다. producer 를 한
번도 보지 않아 `ingress_worker.py` 의 `return SafeInteractionOutcome.UNAVAILABLE` 을 지워도
통과했다. 계약 `interaction-feedback.md` 가 "Every listed outcome has a producer" 를 선언하고
`T007` evidence 가 "신규 test 가 이를 고정한다" 고 적었으나 고정하지 않았다.

**`R-5` — 4 대 5 불일치.** `spec.md` FR-024 가 넷만 적었다. 코드는 다섯을 만든다.

## What Changed

**producer 를 실제로 관측한다.** `_observed_safe_outcomes()` 가 대표 입력을 분류기에 넣고
**나온 값**을 모은다. 어떤 값에 producer 가 없어지면 그 값이 집합에서 빠져 대조가 실패한다.

`already_completed` 에는 producer 가 둘이다 — 소비된 action 과 replay 된 성공 decision. 후자는
`test_a_second_click_gets_already_completed_feedback_without_a_second_decision` 이 실제 두 번
클릭으로 덮으므로 여기서 재현하지 않았다.

**크기를 센다.** `test_the_contract_enumerates_exactly_the_outcomes_the_code_produces` 가 계약
문서의 표를 파싱해 원소와 **크기** 둘 다 비교한다. `R-5` 가 크기를 세지 않아 4 대 5 를 놓친
사례다.

```python
assert listed == produced
assert len(listed) == len(produced)
```
