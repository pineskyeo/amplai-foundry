## Correction To Round 10 Finding `C-12`

round 10 regression lens 는 `decisions.py:771` 의 `raw_token in idempotency_key` guard 를
지우면 "같은 token 의 raw 값이 `governance_decision_results.idempotency_key` 로 영구
저장된다"고 보고하며 **P0** 로 등급했다. **그 결론은 틀렸다.**

두 단계로 직접 측정했다.

| 조건 | 결과 |
|---|---|
| `:771` guard 만 무력화 | 여전히 `IDEMPOTENCY_CONFLICT` 로 거부. durable row 0건 |
| `:771` 과 `:369` 를 함께 무력화 | 거부되지 않음. 새 test 두 건이 실패 |

`_contains_persisted_secret` (`decisions.py:369`, governance transaction 안)가 idempotency
key 의 32-hex 부분문자열을 저장된 token hash 와 대조한다. 이 대조는 sibling token 뿐 아니라
**이번 호출의 token 도** 잡는다. 따라서 `:771` 은 단독 방어선이 아니라 transaction 진입 전의
빠른 중복 확인이다.

lens 는 "full suite green" 만 관측하고 그 결과를 확인 없이 "durable 저장 가능"으로 옮겼다.
이 evidence 가 그 추론을 대체한다. `C-12` 는 P0 가 아니다.

추가한 test 두 건은 그대로 유지한다. 관측 가능한 계약(거부되고 durable row 가 생기지 않는다)을
고정하며, 실효 방어선인 `:369` 를 지킨다.
