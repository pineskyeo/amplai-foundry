바뀌면:\n\n```text\n새 Source 등록\n→ 기존 REQ-0012와 CONFLICTS 또는 SUPERSEDES\n→ 자동 적용 금지\n→ 사용자 승인 요청\n```\n\n---\n\n# 로드맵 완료 Gate도 강화해야 한다\n\n현재 Phase 1B Gate의 문구는 다음과 같습니다.\n\n> repeated ingestion does not
