# Knowledge Index

map.json references repository-owned sources. claims.jsonl and decisions.index.json
start empty; they are not imported knowledge or approval. Preserve source evidence and
historical supersession. Work artifacts live under their feature, not in this index.

The documentation policy's governing_inputs declares exact instruction or decision_ledger
paths and security. The baseline requires AGENTS.md, its workflow and verifier registry;
it imports no private Decisions. App-owned ledgers contribute only applicable active
indexed Decisions and typed references, not their whole historical text. Context validation
reconstructs the complete source, claim and Decision set; removed inputs cannot be hidden
by recalculating the pack hash. Release-guide review and source security remain separate checks.
