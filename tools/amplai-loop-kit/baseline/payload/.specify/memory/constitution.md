# Portable Baseline Principles

Repository-local AGENTS.md and approved product contracts remain authoritative.
Preserve existing files, user edits, domain boundaries and historical decisions.
Use work for authorized implementation and design for design-only requests.
A valid contract, evidence-backed readiness, Context Pack and generated task manifests
precede execution. Actual executable evidence decides PASS; unavailable checks do not.
After convergence, refresh documents before independent contract, recovery and regression
reviews. Blocking findings prevent completion. Gardening is scoped and report-only.
No automatic canonical knowledge promotion, production mutation, publication, trust
change or destructive cleanup is authorized by the baseline.
