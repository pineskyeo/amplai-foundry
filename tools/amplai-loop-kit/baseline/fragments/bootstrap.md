repository rules and approval boundaries remain authoritative. Read .ai-team/README.md
and only task-relevant policies. Common skills live in .agents/skills; Claude mirrors
point to that same source. Run `python3 scripts/loopctl.py doctor` before feature work.

executable generated tasks. Implement → verify/repair → converge → document freshness →
independent review → scoped report-only gardening → handoff. Preserve user content,
