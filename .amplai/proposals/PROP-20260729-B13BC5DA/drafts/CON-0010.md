# Hermes는 교체 가능한 Client Partner이자 Work Manager다

## Definition

Hermes는 사용자 자연어 요청, 대화 session, 개인 선호, 일정과 Slack·Telegram 같은 채널을 조율하고 AMPLAI capability를 호출하는 Client Partner 및 Work Manager 후보다. 필요하면 Claude Code, Codex 또는 사내 GLM 같은 전문 Agent에 작업을 위임하고 결과를 통합한다.

Hermes의 개인 메모리에는 사용자 응답 스타일, 최근 대화와 단기 실행 힌트를 둘 수 있다. 프로젝트 architecture, decision, ontology, policy와 provenance가 있는 장기 지식은 Hermes가 직접 canonical knowledge로 쓰지 않고 AMPLAI Source와 Proposal 흐름으로 보낸다.

Hermes는 `submit_intent`, project/proposal 조회, Proposal action 제출과 job 조회처럼 제한된 AMPLAI 계약만 호출한다. Hermes는 프로젝트를 최종 확정하거나 Proposal 상태를 자체 memory에서 변경하지 않으며, AMPLAI 검증 없이 Git, shell, canonical write 또는 Worker 실행을 수행하지 않는다.
