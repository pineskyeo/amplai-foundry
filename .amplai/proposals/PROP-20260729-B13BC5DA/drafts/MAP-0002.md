# AMPLAI Platform Map

## Integration

- [[AMPLAI에서 MCP는 기능과 지식을 노출하는 Adapter다]]
- [[External Agent Mode는 외부 실행기가 AMPLAI 기능을 호출하는 방식이다]]
- [[초기 AMPLAI는 External Agent Mode부터 시작한다]]

## Roles

- [[AMPLAI Runtime은 외부 Agent Host와 독립적으로 프로젝트 지능을 제공한다]]
- [[프로젝트가 Memory를 소유하고 Runtime은 이를 사용한다]]
- [[Hermes는 교체 가능한 Client Partner이자 Work Manager다]]
- [[Implementation Agent는 위임받은 변경을 구현하고 검증한다]]
- [[Governor는 위험도와 고영향 의미 변경의 승인 경계를 집행한다]]
- [[AMPLAI 역할 경계는 Knowledge Layer·Governor·Work Manager·Implementation Agent를 분리한다]]
- [[Messenger Proposal Control은 channel adapter와 AMPLAI authority를 분리한다]]
- [[메신저 Proposal Action은 AMPLAI가 재검증하고 승인과 Apply를 분리한다]]
- [[Knowledge Steward는 event-driven worker이고 Runtime은 상주 서비스다]]

## Architecture And Open Questions

- [[초기 배포는 Modular Monolith로 시작한다]]
- [[Memory Layer는 Domain Contract와 Repository Port를 소유한다]]
- [[MCP Gateway를 독립 서비스로 분리하는 시점은 언제인가]]
- [[운영 Memory와 Canonical Knowledge의 저장 경계는 어디인가]]
- [[Project Memory의 Source of Truth와 Source Store 경계는 어디까지인가]]
- [[Knowledge Steward의 초기 모델 라우팅과 평가 정책은 무엇인가]]
- [[Hermes 개인 메모리를 AMPLAI Intake로 승격하는 trigger는 무엇인가]]
