# Memory Candidate는 불변 Source 근거와 비교 가능한 의미 구조를 가진 제안이다

## Definition

Memory Candidate는 Agent run, source ingestion 또는 사람의 관찰에서 발견한 지식 가능성이다. LLM은 candidate와 관계를 제안할 수 있지만 canonical knowledge를 직접 쓰거나 수정하지 않는다.

Candidate는 statement, immutable Source ID, 확인 가능한 evidence locator, confidence, interpretation note와 extractor/model·prompt·ontology·policy version 같은 재현 metadata를 가져야 한다. Semantic comparison을 위해 project scope, 정규화된 proposition, modality, polarity와 constraints도 보존할 수 있다. 이 필드는 비교 입력이며 아직 domain ontology나 최종 schema를 확정하지 않는다.

Candidate는 suggested kind에 따라 검색 범위를 제한하지 않는다. 기존 knowledge 및 unapproved candidate와의 중복·충돌 검토, deterministic validation, proposal과 review를 거쳐야 [[Canonical Knowledge는 검토된 공식 지식이다]]로 승격될 수 있다.
