# Candidate의 의미 identity, 중복과 충돌은 어떻게 판정하는가

## Question

Project-scoped Source content identity와 semantic identity를 어떻게 구분하고, 표현이 다른 Candidate를 기존 active knowledge 또는 unapproved candidate와 어떤 관계로 판정하는가?

## Decision Needed

- 비교 corpus에 active, candidate, superseded status를 각각 어떤 권위로 포함할 것인가?
- proposition, modality, polarity, constraints와 project scope를 어떤 최소 signature로 사용할 것인가?
- 초기 relation vocabulary와 kind-aware operation policy는 무엇인가?
- `NEW`와 `UNCERTAIN`을 가르는 confidence/risk 기준은 무엇인가?
- `UNCERTAIN` ComparisonResult를 어디에 durable하게 보존하고 누가 review하는가?
- deterministic retrieval, bounded semantic judge와 향후 embedding의 책임을 어떻게 구분하는가?

이 질문은 [[Knowledge Steward Golden Set과 replay regression 평가]] 결과와 [[Knowledge Intake의 초기 자동 승인 경계는 어디까지인가]] 결정을 함께 검토해야 한다.
