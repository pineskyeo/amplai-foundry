# Knowledge Steward Golden Set은 semantic comparison과 governed routing을 평가한다

## Hypothesis

Labeled pairwise cases와 deterministic replay를 유지하면 Semantic Comparison 변경의 duplicate creation, false merge, false create, scope leakage와 forbidden apply regression을 측정할 수 있다.

## Dataset

- exact/normalized Source duplicate
- 다른 표현의 semantic duplicate
- constraint가 추가된 refinement
- polarity 또는 modality가 반대인 conflict
- 같은 용어를 쓰지만 다른 의미인 new candidate
- 충분한 근거가 없는 uncertain case
- 같은 proposition의 cross-kind 및 Question/Decision epistemic-state 차이
- cross-project 유사 표현
- active, candidate와 superseded target 차이

## Method

각 replay는 candidate set, retrieval signals, policy version, evidence, relation recommendation, recommended operation과 review requirement를 기록한다. Semantic duplicate case는 `CREATE`를 추천하지 않아야 하며 `REFINES`, `CONFLICTS`, `UNCERTAIN`은 각 governed outcome으로 routing되고 자동 apply되지 않아야 한다. Cross-project case는 Phase 1A qualified resolution 전에 match되지 않아야 한다.

Relation accuracy, false-merge rate, false-create rate, duplicate creation rate와 review queue load를 비교한다. Model 또는 prompt 변경의 허용 tolerance와 pass threshold는 baseline 측정 뒤 정한다.
