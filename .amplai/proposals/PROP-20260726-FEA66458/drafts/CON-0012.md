# Governor는 위험도와 고영향 의미 변경의 승인 경계를 집행한다

## Definition

Governor는 Work Manager와 Implementation Agent가 사용할 수 있는 capability, risk classification, 필요한 승인과 canonical promotion 조건을 집행하는 정책 역할 후보다. 기존 [[LLM은 Canonical Knowledge를 직접 변경하지 않고 Proposal과 검토를 거친다]] 원칙을 runtime workflow에 적용한다.

Governor는 Decision 확정, 기존 Decision 변경 또는 폐기, architecture boundary, ontology 의미, policy·권한, production action과 breaking change를 고영향 의미 변경으로 분류할 수 있다. Governor가 별도 service인지 domain module인지와 정책을 구성하는 actor는 이 개념에서 확정하지 않는다.
