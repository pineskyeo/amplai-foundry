# Memory Candidate는 불변 Source 근거를 가진 구조화된 제안이다

## Definition

Memory Candidate는 Agent run, source ingestion 또는 사람의 관찰에서 발견한 지식 가능성이다. LLM은 candidate와 관계를 제안할 수 있지만 canonical knowledge를 직접 쓰거나 수정하지 않는다.

Candidate는 statement, immutable Source ID, 확인 가능한 evidence range, confidence, interpretation note와 extractor/model·prompt·ontology·policy version 같은 재현 metadata를 가져야 한다. 근거 없는 단정, 원문보다 강한 해석, 의미 불일치나 상충 근거는 Proposal 전에 거부한다.

Candidate는 중복과 충돌 검토, deterministic validation, proposal과 review를 거쳐야 [[Canonical Knowledge는 검토된 공식 지식이다]]로 승격될 수 있다.
