# Meta-loop는 trigger 기반 replay와 review를 거치는 제한된 개선 흐름이다

## Definition

Meta-loop는 개별 task의 다음 step을 고르는 Loop가 아니다. 반복 실패, 사용자 수정 피드백, regression score 하락, 정기 평가 또는 비용·latency 급증 같은 trigger 뒤 여러 실행 결과를 분석해 개선 가설을 만든다.

개선 가설은 sandbox 또는 replay로 평가하고 prompt, tool policy, Harness, 평가 기준 또는 공식 지식 변경 proposal으로 제출한다. Meta-loop는 상주하며 자유롭게 자기 코드를 바꾸는 Agent가 아니며, Governor review와 승인 또는 rollback을 거친다.
