# 공식 지식 후보와 주장은 불변 Source의 확인 가능한 근거를 가져야 한다

## Principle

Active 공식 지식은 최소 하나의 source record를 `source_refs`로 가리켜야 한다. 지식 후보와 Proposal의 각 핵심 주장은 검토자가 원문에서 확인할 수 있는 evidence locator를 가져야 한다. Source 원문은 LLM 요약이 아니라 provenance의 기준이다.

Source record 자체는 provenance의 시작점이므로 다른 source reference를 의무로 요구하지 않는다. 모델 출력이 달라져도 immutable Source, content hash, extraction result와 review decision을 통해 해석과 변경 이력을 확인할 수 있어야 한다.
