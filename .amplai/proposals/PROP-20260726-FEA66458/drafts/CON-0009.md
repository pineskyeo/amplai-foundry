# AMPLAI Runtime은 외부 Agent Host와 독립적으로 프로젝트 지능을 제공한다

## Definition

AMPLAI는 하나의 Agent runtime을 대체하는 범용 실행기가 아니다. 프로젝트가 공유하는 canonical knowledge, ontology, policy, proposal과 evaluation 경계를 runtime과 독립적으로 제공하는 프로젝트 중심 AI 운영체제 후보다.

Hermes, Claude Desktop, Codex CLI와 사내 메신저 Bot 같은 external host는 AMPLAI capability를 호출할 수 있지만 AMPLAI의 지식과 정책을 소유하지 않는다. 어떤 host가 교체되거나 중단돼도 프로젝트 지식과 governance는 유지돼야 한다.
